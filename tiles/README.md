# Офлайн-тайлы карты

Поместите тайлы выбранного региона в этот каталог по схеме:

```text
tiles/{z}/{x}/{y}.png
```

Например:

```text
tiles/14/9905/5124.png
```

Интерфейс не обращается к внешним картографическим серверам. Если локальных
тайлов для текущих координат нет, Leaflet показывает тёмную координатную
подложку, а маршрут, точки замеров и положение робота продолжают работать.

Перед загрузкой тайлов проверьте лицензию и правила распространения выбранного
поставщика картографических данных.
