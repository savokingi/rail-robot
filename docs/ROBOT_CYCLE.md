# Цикл работы робота

## Блок-схема

```mermaid
%%{init: {'theme':'base','themeVariables': {'fontSize':'16px'}, 'flowchart': {'curve':'basis','nodeSpacing': 12,'rankSpacing': 14,'padding': 6,'useMaxWidth': false}}}%%
flowchart TB
    A[Старт] --> B[Робот едет]
    B --> C{Есть поезд / авария?}
    C -->|Да| Z[Покидает путь]
    C -->|Нет| D{Нужна остановка?}
    D -->|Да| E[Останавливается]
    D -->|Нет| B
    E --> F[Проводит замеры]
    F --> G{Норма?}
    G -->|Да| H[Едет дальше]
    G -->|Нет| I[Маркирует дефект]
    I --> J[Записывает в таблицу]
    J --> H
    H --> B
    Z --> K[Ожидание сигнала]
    K --> B
```

## Кратко

Робот едет по маршруту, но перед остановкой проверяет, нет ли поезда или аварийной ситуации. Если опасность есть, он покидает путь и переходит в безопасный режим. Если всё спокойно, он останавливается для замера, проверяет показатели, при норме продолжает движение, а при отклонениях маркирует дефект и записывает его в таблицу, затем снова едет дальше.
