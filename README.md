# Rail Robot

Локальная панель управления и аналитики железнодорожного робота. Сейчас ноутбук
может заменить Raspberry Pi, а ESP — работать как аппаратный эмулятор по USB.

> `docs/ALGORITHM.md`, `docs/ROBOT_CYCLE.md`, `docs/SIGNAL_FLOW.md` и старый
> `sensorEmu.ino`
> содержат ранние проектные материалы. Актуальный тестовый протокол описан ниже.

## Быстрый показ без ESP

```powershell
npm install
npm run demo
```

Открыть `http://localhost:3000`. В этом режиме сервер сам эмулирует GPS, мотор,
энкодер колеса, твердомер и сервопривод краски.

## Проверка с настоящей ESP-эмулятором

1. Прошить `app/esp-emulator/espEmulator.ino` в ESP8266 или ESP32.
2. Подключить плату к ноутбуку по USB. Скорость Serial: `115200`.
3. Запустить сервер, явно указав порт:

```powershell
npm install
npm start -- --port=COM5
```

Если подключена только одна подходящая USB-плата, сервер попробует найти порт
автоматически. Вместо аргумента можно задать переменную `SERIAL_PORT`.

## Что работает

- офлайн-карта небольшого реального участка железной дороги из OpenStreetMap;
- сопоставление GPS с ближайшей точкой железнодорожной линии;
- относительный километраж внутри тестового участка в формате `0+123`;
- автоматический цикл: движение, остановка каждые 5 м, замер, маркировка дефекта,
  продолжение движения;
- запуск, пауза, продолжение и остановка рейса;
- ручное движение вперёд/назад из бокового меню;
- маршрут, кликабельные точки замеров, таблица, график и журнал событий;
- сохранение завершённых рейсов в `data/sessions.json`.

Порог нормы и модели реальных датчиков пока намеренно не зашиты: ESP возвращает
готовые поля `hardness` и `status`, поэтому физический твердомер можно выбрать
позже без переделки панели.

## Протокол ноутбук/Raspberry Pi ↔ ESP

Обмен идёт по Serial в формате JSON Lines: один JSON-объект на строку.

Команды сервера: `heartbeat`, `reset`, `move`, `stop`, `measure`, `mark`.
Ответы ESP: `ack`, `telemetry`, `measurement`, `marked`.

Пример телеметрии:

```json
{"type":"telemetry","lat":56.3251594,"lon":43.9496451,"speed":1.25,"distanceMeters":5.1,"wheelTicks":102,"motor":"forward"}
```

Для безопасности мотор останавливается, если ESP не получает `heartbeat` дольше
1,2 секунды.

## Карта

Файл `data/railway-line.geojson` хранится в проекте, поэтому интернет во время
работы не нужен. Это небольшой тестовый фрагмент OSM way `433222646`, а не вся
Нижегородская область. Для реального участка файл позднее заменяется выгрузкой
нужной линии из Overpass, логика сервера и интерфейс остаются теми же.
