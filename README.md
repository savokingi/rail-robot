# 🚆 Автономный диагностический робот для выявления дефектов ЖД пути

Проект разработан для участия в испытаниях по направлению «Диагностирование» (Задание № 2 — Автономные беспилотные технологии). 
Робот представляет собой автономную мобильную платформу, адаптированную под узкую колею **750 мм**, предназначенную для автоматического обнаружения, классификации и маркировки критических дефектов верхнего строения пути.

## 🎯 Решаемые задачи и типы дефектов

Робот работает в условиях неизвестного заранее расположения и количества дефектов. Система самостоятельно выявляет три категории неисправностей:
1. **Отсутствие стыковых болтов** на одном конце рельса.
2. **Стыковой зазор** размером более **35 мм**.
3. **Перекос пути** (приподнятый рельс) высотой более **12 мм**.

По результатам заезда робот маркирует дефекты краской и формирует отчет с привязкой к координатам.

## 🛠 Аппаратная архитектура

Конструкция робота разделена на функциональные узлы:
* **Механика:** Рама с четырьмя направляющими роликами под колею 750 мм. Боковые каретки с рычагами обеспечивают надежное прижатие к рельсам. Исполнительные механизмы на базе зубчатых передач.
* **Сенсорика:**
  * **ИК-датчик препятствий (LM393):** Установлен в зоне стыка. Используется для детекции зазоров > 35 мм и отсутствия болтов (по изменению уровня отраженного сигнала).
  * **Акселерометр:** Размещен на раме. Фиксирует угол наклона платформы при подъеме одного из рельсов (перекос > 12 мм).
  * **Энкодер:** Установлен на приводном колесе для точной одометрии (привязки дефектов к координате).
  * **Центральная камера:** Визуальное подтверждение дефекта и фотофиксация для отчета.
* **Электроника:** Управляющая плата, модуль связи UDP/Wi-Fi, автономное питание (аккумулятор + схема зарядки), узел маркировки (краска).

## 🧠 Техническая реализация и алгоритмы

### 1. Логика совместной работы датчиков (Sensor Fusion)
Система использует мультисенсорный подход для минимизации ложных срабатываний:
* **Контроль стыков:** ИК-датчик непрерывно опрашивается с высокой частотой. При падении уровня отраженного сигнала ниже заданного порога (калибруется под зазор >35мм или пустоту от болта) фиксируется событие.
* **Контроль перекоса:** Данные с акселерометра (оси X/Y) фильтруются (например, скользящее среднее или фильтр Калмана) для отсечения вибраций. При превышении порога наклона (соответствующего подъему рельса на 12 мм) фиксируется событие.
* **Синхронизация:** В момент срабатывания любого датчика текущее значение энкодера (координата) и кадр с камеры сохраняются в лог.

### 2. Математика одометрии (Энкодер)
Расчет пройденного расстояния и перевод в тики (ticks) реализуется по формуле:
```python
CL = 58.1 * 3.14159 * 1000  # Длина окружности колеса (в мм/м, согласно конфигурации)
ticks = (meters / CL) * 1200  # 1200 тиков на оборот

### 3. Программный стек и протокол управления
Управление реализовано на **Python**. Связь между оператором и роботом осуществляется по протоколу **UDP** (для минимизации задержек).
Робот поддерживает следующий набор строковых команд:
* `|f;` — движение вперед (Forward)
* `|b;` — движение назад (Backward)
* `|p;` — экстренная остановка (Stop)
* `|u;` — сброс показаний энкодера (Reset)

### 4. Логирование и формат данных
Все события записываются в файл `log.txt`. Формат записи содержит:
* Временную метку (Timestamp).
* Тип обнаруженного дефекта (`Bolt_Missing`, `Gap_Over_35`, `Rail_Misalignment`).
* Координату по энкодеру (в тиках/метрах).
* Путь к сохраненному изображению с камеры.

### 5. Автономность и безопасность
Робот работает в полуавтономном режиме (участие оператора требуется только для старта и приема отчета — >80-90% времени работы). Реализованы защитные протоколы:
* При потере UDP-связи — автоматическая остановка.
* При падении заряда аккумулятора ниже критического уровня — остановка и переход в безопасное состояние.
